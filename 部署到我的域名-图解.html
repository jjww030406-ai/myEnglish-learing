📲 从零把网站放到你的域名 jjww.new.tg

你现在已经有了：① 域名 jjww.new.tg（已注册）② 网站文件（网盘里的 english-learning 文件夹）。下面照着点，分两阶段：先让网站上线，再绑到你的域名。
全程不用敲任何命令。每一步都标了要点，跟着图走就行。卡住就把页面截图发我。
阶段 A：先让网站在 GitHub Pages 上线

1打开 GitHub 并登录

浏览器输入 github.com。没有账号点 Sign up 用邮箱注册（免费）；有就 Sign in 登录。

2进入你建的仓库 english-learning

登录后，点你头像旁边找 english-learning 仓库进去。如果里面还没传文件，就先把网盘下的 english-learning 文件夹内容拖进去、点绿色 Commit changes（下面第 4 步会用到）。

3开启 Pages（让网站能被访问）

进仓库点 Settings → 左边 Pages → Source 选 main，文件夹选 /(root) → 点 Save。

4等 1～2 分钟，先得到一个 github.io 网址

保存后等一会儿，打开上面的网址能看网站了（先别管它带尾巴，阶段 B 会换成你的域名）。

阶段 B：把网站绑到你的域名 jjww.new.tg

5在 GitHub 填你的域名

还在 Settings → Pages 这个页面，找 Custom domain 输入框，填 jjww.new.tg → 点 Save。GitHub 会提示你去加 DNS（下一步）。

6去你买域名的地方，加 4 条解析记录

登录你注册 jjww.new.tg 的那个网站（域名控制台），找「域名解析 / DNS 设置」。给根域名加下面 4 条 A 记录（主机记录填 @ 或留空）：

类型主机记录记录值（IPv4 地址）
A@（或空）185.199.108.153
A@（或空）185.199.109.153
A@（或空）185.199.110.153
A@（或空）185.199.111.153

这 4 个 IP 是 GitHub Pages 官方服务器地址，所有 GitHub 用户都一样，照抄即可。

7回到 GitHub 看它变绿 + 自动上锁

DNS 生效一般几分钟到几小时。回到 GitHub 的 Pages 页面，看到域名旁边变成 ✓ DNS check successful 且带小锁，就成了。

8🎉 手机打开你的域名

注意网址后面带 /english-learning/ 这个小尾巴（因为仓库叫这名字）。想去掉尾巴、直接 jjww.new.tg 就打开，把文件传到一个名字叫 你的用户名.github.io 的仓库即可，其它步骤一样。
