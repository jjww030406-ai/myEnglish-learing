📦 把「英语从零学」部署到 GitHub Pages

不用敲命令、不用装软件，全程在网页上点。跟着 6 步走，最后得到一个手机能直接打开的网址。

1打开 GitHub 并登录

浏览器打开 github.com。没有账号就点 Sign up 用邮箱注册一个（免费）。

2新建一个仓库（Repository）

点右上角 ＋ → New repository。仓库名填 english-learning，一定选 Public，其它不动，点 Create repository。

Public 是免费的；选 Private 的话 GitHub Pages 要付费，所以选 Public。

3把网站文件传上去（直接拖，不用命令）

新建仓库后的页面里，点 “uploading an existing file” 那行字，把 english-learning 文件夹里的所有内容一起拖进虚线框。

是拖「文件夹里面的内容」，不是拖整个文件夹本身；确保 index.html 在根目录。

4提交（Commit）

在最下面的说明框随便写点字（比如"首次上传网站"），点绿色的 Commit changes。

5开启 GitHub Pages

进仓库后点顶部的 Settings → 左侧找 Pages → Source 选 main 分支、文件夹选 /(root) → 点 Save。

6等一两分钟，手机打开网址 🎉

保存后等 1～2 分钟，浏览器输入上面的网址即可。✅ 这是 https 网址，手机直接开，🎤 语音识别也能用。

要是打不开，过两分钟再试；首次部署 GitHub 要构建一会儿。

💡 以后怎么更新网站？

改完文件后，回到这个仓库，把新文件再拖进去覆盖、点 Commit changes 就行；Pages 会自动重新发布，不用重来。
